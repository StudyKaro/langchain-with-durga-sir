Define schema:
-------------
- A python class require 
- extend BaseModel class
# BaseModel is Parent class must be extend
# reponsible to define schema and validation
# in schema every element by default mandatoy
# schema mean define type and fields name

example:
 
from pydantic import BaseModel
class Student(BaseModel):
    name:str 
    age: int
    course:str
s = Student(name="Vandhu",age=34,course="Moksha Shashtra") 
# there is no such param constructor bcoz take care by BaseModel 
print(s)
# s directly print magic method take care by BaseModel

# s1 = Student(name="Vandhu",age=34) # validation error for course

How LLM know about need to return data in pydantic or defined schema format not AIMessage
- llm has with_structured_output() function
- pass pydantic object

Example :
from pydantic import BaseModel
from langchain_openai import ChatOpenAI
import os
llm = ChatOpenAI(model='gpt-5-nano', api_key=os.getenv("OPENAI_API_KEY"))
class Student(BaseModel):
    name:str 
    age: int
    course:str
    
# bind schema to llm 
schema_llm = llm.with_structured_output(Student)

query = input("You: ")
response = schema_llm.invoke(query)
print(response)

# By default in pydantic schema all fields are mandatory
# how to make optional ex:  experience field for fresher.
# use None 
Example :
from pydantic import BaseModel
from langchain_openai import ChatOpenAI
import os
llm = ChatOpenAI(model='gpt-5-nano', api_key=os.getenv("OPENAI_API_KEY"))
class Student(BaseModel):
    name:str 
    age: int | None = None
    course:str | None = None
    
# bind schema to llm 
schema_llm = llm.with_structured_output(Student)

query = input("You: ")
response = schema_llm.invoke(query)
print(response)
